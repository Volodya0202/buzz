## Перед созданием PR

Перед началом работы поищите открытые PR и задачи, чтобы избежать дублирования.

Для любых нетривиальных изменений рекомендуется сначала открыть Issue с описанием проблемы и предлагаемого решения.

Buzz приветствует изменения, созданные с помощью ИИ-ассистентов. Однако вы несете полную ответственность за качество и работоспособность финального кода.

Мы используем слияние типа **Squash and Merge**, поэтому название вашего PR станет темой коммита в ветке `main`. Используйте формат [Conventional Commits](https://www.conventionalcommits.org/): `feat(mcp): add get_feed_actions tool`.

### Подпись коммитов (DCO)

```bash
git commit -s
```

Каждый коммит требует подписи DCO (Developer Certificate of Origin). Флаг `-s` добавляет строку `Signed-off-by`.

## Настройка окружения разработки

### Требования

| Инструмент | Версия | Примечания |
|---|---|---|
| Rust | 1.88+ | Установка через [rustup](https://rustup.rs/) |
| Node.js | 24+ | Требуется для десктопа и `just ci` |
| pnpm | 10+ | Менеджер пакетов |
| Flutter | 3.41+ | Требуется для мобильного клиента |
| Docker | 24+ | Для Postgres, Redis, MinIO |
| `just` | latest | Утилита запуска задач (`cargo install just`) |

В репозитории используется [Hermit](https://cashapp.github.io/hermit/) для фиксации версий инструментов. Активируйте его в командной строке:

```bash
. ./bin/activate-hermit
```

### Первый запуск

```bash
cp .env.example .env
just setup
just build
```

## Запуск тестов

```bash
just test-unit    # Быстрые модульные тесты без поднятия внешних сервисов
just test         # Полный набор тестов
just check        # Проверка форматирования (rustfmt, clippy, biome)
just ci           # Полный цикл проверок CI
```

---

## Стиль кода

- **Rust:** используется `cargo fmt` и `cargo clippy`. Запускайте `just check` перед коммитом.
- **TypeScript / React:** форматирование и линтинг осуществляются через [Biome](https://biomejs.dev/): `pnpm check`.

## Как добавить новый тип события (Event Kind)

1. Зарегистрируйте новую константу в `crates/buzz-core/src/kind.rs`.
2. Добавьте её в массив `ALL_KINDS`.
3. Реализуйте обработчик в `crates/buzz-relay/src/handlers/event.rs`.
4. Напишите интеграционный тест в `buzz-test-client`.
