# 🐝 Buzz Projects — Forge на базе Nostr

> Кто-то отправляет исправление. Buzz создает канал для ветки. CI-агент запускает тесты и отправляет результаты в канал. Коллега проверяет дифф, утверждает его — это криптографически подписанное событие. Мердж. Воркфлоу проводит интеграцию. Канал архивируется и становится вечным архивом того, зачем этот код был создан.

## Модель проекта

Проект живет на релее. Домен `myproject.com` открывает главную страницу проектов. Нажмите на репозиторий — и вы на `repoa.myproject.com`. Тот же URL отдает HTML браузеру и отвечает на вызовы `git clone`.

Передача Git идет по стандартному протоколу Smart HTTP (`git clone`, `git push`). Ваши коммиты подписываются вашим npub.

Стандартные метаданные NIP-34 (kind:30617) описывают репозитории, а Buzz расширяет их тегами `buzz-protect` для защиты веток и `buzz-channel` для привязки каналов.

## Один проект — множество репозиториев

Реальная разработка охватывает множество репозиториев: релей, десктоп, мобильное приложение. Buzz группирует репозитории в единый проект через событие `kind:30621` (NIP-MP).

## Ветки как каналы

Ветка — это живое обсуждение:
- При создании ветки Buzz открывает тематический канал.
- Патчи, комментарии код-ревью, результаты CI и решение о мердже публикуются в этот канал.
- После слияния ветки канал архивируется и сохраняется навсегда. Никакого переключения между десятком вкладок. Канал *является* пул-реквестом, дашбордом CI и тредом обсуждения одновременно.
